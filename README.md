# 💊 New Drug Approvals Dashboard (2002–2023)

## 📌 Executive Summary
An interactive Power BI dashboard designed to analyze key trends, therapeutic categories, dosage forms, active pharmaceutical ingredients (APIs), and manufacturer metrics for drug approvals from 2002 through 2023. 

This project bridges **Data Science** and **Pharma Regulatory Analytics**, translating complex pharmaceutical data into actionable insights for market analysis, regulatory benchmarking, and portfolio planning.

## 🗝️ Key Features & Business Insights

* **Key Performance Metrics (KPIs):**
  * **Highest Approval Year:** Peak activity identified in 2018.
  * **Drug Volume:** Total drug approvals tracked across 7 major pharmaceutical companies[cite: 1].
  * **Patient Metrics:** Summarizes total patient metrics (~525M total / ~524.55 average)[cite: 1].
* **Therapeutic Category Analysis:** Interactive Donut Chart categorizing approvals across Pain, Fever, Diabetes, Neuropathy, Cardio, Asthma, and Infection[cite: 1].
* **Manufacturing & Dosage Breakdown:**
  * **Treemap:** Visualizes distribution across dosage forms (Inhaler, Gel, Injection, Tablet, Syrup, Capsule)[cite: 1].
  * **Company Performance:** Horizontal bar chart displaying drug counts by top manufacturers (Pfizer, Sun Pharma, Novartis, Roche, AstraZeneca, Cipla, GSK)[cite: 1].
* **Active Ingredient Mapping:** Bar chart linking active ingredients (e.g., Amoxicillin, Salbutamol, Paracetamol, Ibuprofen, Metformin, Atorvastatin, Gabapentin) to dosage form counts[cite: 1].
* **Temporal Trend Analysis:** Line graph tracking approval volume fluctuation year-over-year[cite: 1].
* **Geographic Distribution:** Map integration analyzing patient reach across key global markets[cite: 1].
* **Dynamic Slicing:** Multi-field slicers for Approval Year, Dosage Form, Active Ingredient, Therapeutic Disease, Company, and Country[cite: 1].
